# Como ajudar

Valeu por querer ajudar. Deixei o projeto simples de propósito, é só html css e js puro.

## Passo a passo

1. Mexe nos arquivos direto (index.html, css/styles.css, js/app.js)
2. Depois é só abrir o index.html no navegador pra testar, não precisa rodar nada
3. Abre o PR falando o que você mudou, se mexer no visual manda print junto

## Só uns combinados

- Tem que continuar funcionando com dois cliques, sem servidor e sem npm
- Não coloca coisa que obrigue internet, cdn com fallback tudo bem
- Os dados ficam no localStorage, mantém a mesma chave
- Não muda o visual sem necessidade, e se mudar explica no PR
